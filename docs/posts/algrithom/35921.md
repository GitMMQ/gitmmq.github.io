<p>KMP算法解决的是字符串模式匹配定位问题</p>
<p>主串：  ABACBFG  —i<br/>模式串：ABAD     —j</p>
<h2 id="简单算法："><a class="headerlink" href="#简单算法：" title="简单算法："></a>简单算法：</h2><p>从左到右一个一个匹配，遇到不匹配，i回到i-j+1,j回到0，重新匹配（不考虑模式串本身特性–最大前后缀数）</p>
<pre><code>/**

<ul>
<li><p>@param ts 主串</p>
</li>
<li><p>@param ps 模式串</p>
</li>
<li><p>@return 如果找到，返回在主串中第一个字符出现的下标，否则为-1</p>
</li>
</ul>
<p> */</p>
<p>public static int bf(String ts, String ps) {</p>
<pre><code>char[] t = ts.toCharArray();

char[] p = ps.toCharArray();

int i = 0; // 主串的位置

int j = 0; // 模式串的位置

while (i &amp;lt; t.length &amp;amp;&amp;amp; j &amp;lt; p.length) {

   if (t[i] == p[j]) { // 当两个字符相同，就比较下一个

       i++;

       j++;

   } else {

       i = i - j + 1; // 一旦不匹配，i后退

       j = 0; // j归0

   }

}

if (j == p.length) {

   return i - j;

} else {

   return -1;

}
</code></pre>
<p>}<br/></p></code></pre>
<p>优化：考虑先前匹配的结果和模式串的特点（最长前缀），i可以不动，只移动j，到位置k</p>
<h2 id="寻找k"><a class="headerlink" href="#寻找k" title="寻找k"></a>寻找k</h2><p>规律： 最前面的k个字符和j之前的最后k个字符是一样的</p>
<p> <img alt="alt text" src="http://thyrsi.com/t6/625/1543997868x1822611383.jpg" title="示例"/></p>
<h2 id="推导："><a class="headerlink" href="#推导：" title="推导："></a>推导：</h2><pre><code>T[i] != P[j] 
T[i-j ~ i-1] == P[0 ~ j-1] 
P[0 ~ k-1] == P[j-k ~ j-1]
==&gt; T[i-k ~ i-1] == P[0 ~ k-1]
</code></pre>
<h3 id="由于每个j对应的k都可能不同，可以找到一个j-k对应关系-next-j-k"><a class="headerlink" href="#由于每个j对应的k都可能不同，可以找到一个j-k对应关系-next-j-k" title="由于每个j对应的k都可能不同，可以找到一个j~k对应关系 next[j] = k"></a>由于每个j对应的k都可能不同，可以找到一个j~k对应关系 <code>next[j] = k</code></h3><h2 id="四个规则"><a class="headerlink" href="#四个规则" title="四个规则"></a>四个规则</h2><ol>
<li>j在最左边了，匹配失败，i指针后移</li>
<li><code>P[0 ~ k-1] == p[j-k ~ j-1] 且 P[k] == P[j]时，next[j+1] == k + 1 == next[j] + 1，找到最大公共前后缀数</code></li>
<li><code>P[0 ~ k-1] == p[j-k ~ j-1] 且 P[k] != P[j]时，k=next[k]（在位置k不匹配了，往下找不到更长的前缀字串了，但可以根据k找到最长前后缀数）</code></li>
</ol>
<blockquote>
<p>递归思想: 不匹配，递归找不匹配位置k前面有没有相同前缀后缀，一直找到next[0]=-1为止，此时next[j]=k+1=-1+1=0</p>
</blockquote>

<pre><code>public static int[] getNext(String ps) {

<pre><code>char[] p = ps.toCharArray();

int[] next = new int[p.length];

next[0] = -1;

int j = 0;

int k = -1;

while (j &amp;lt; p.length - 1) {

   if (k == -1 || p[j] == p[k]) {

       next[++j] = ++k;

   } else {

       k = next[k];

   }

}

return next;
</code></pre>
<p>}<br/></p></code></pre>
<h3 id="当P-j-x3D-x3D-P-next-j-已经与主串不匹配-96"><a class="headerlink" href="#当P-j-x3D-x3D-P-next-j-已经与主串不匹配-96" title="当P[j] == P[next[j]],已经与主串不匹配`"></a>当P[j] == P[next[j]],已经与主串不匹配`</h3><pre><code>public static int[] getNext(String ps) {

<pre><code>char[] p = ps.toCharArray();

int[] next = new int[p.length];

next[0] = -1;

int j = 0;

int k = -1;

while (j &amp;lt; p.length - 1) {

   if (k == -1 || p[j] == p[k]) {

       if (p[++j] == p[++k]) { // 当两个字符相等时要跳过

          next[j] = next[k];

       } else {

          next[j] = k;

       }

   } else {

       k = next[k];

   }

}

return next;
</code></pre>

<h2 id="匹配过程"><a class="headerlink" href="#匹配过程" title="匹配过程"></a>匹配过程</h2><pre><code>public static int KMP(String ts, String ps) {

<pre><code>char[] t = ts.toCharArray();

char[] p = ps.toCharArray();

int i = 0; // 主串的位置

int j = 0; // 模式串的位置

int[] next = getNext(ps);

while (i &amp;lt; t.length &amp;amp;&amp;amp; j &amp;lt; p.length) {

   if (j == -1 || t[i] == p[j]) { // 当j为-1时，要移动的是i，当然j也要归0

       i++;

       j++;

   } else {

       // i不需要回溯了

       // i = i - j + 1;

       j = next[j]; // j回到指定位置

   }

}

if (j == p.length) {

   return i - j;

} else {

   return -1;

}
</code></pre>
<p>}<br/></p></code></pre>
