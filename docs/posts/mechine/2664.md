<p>Bagging（Bootstrap Aggregating）是一种集成学习方法，旨在提高模型的稳定性和泛化能力。它通过随机从训练集中有放回地抽取样本，然后训练多个独立的基本模型，最终通过投票或取平均来融合这些模型的预测结果。随机样本抽取和多模型组合有助于减小模型的方差，提高整体性能。</p>
<p>以下是使用 Python 的 <code>scikit-learn</code> 库实现 Bagging 的示例代码。我们将使用决策树作为基本模型：</p>
<p>首先，确保已安装 <code>scikit-learn</code> 库，可以通过以下命令安装：</p>
