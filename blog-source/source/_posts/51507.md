<p>用于分类和回归的非监督学习方法，通过简单的决策规则（if-else）预测目标</p>
<h2 id="优缺点"><a class="headerlink" href="#优缺点" title="优缺点"></a>优缺点</h2><ul>
<li>思想简单，可视乎表达，易理解，可以处理多分类问题</li>
<li>可能会过拟合，此时需要剪枝、采用设置最小样本数目或树的深度</li>
<li>基于启发式算法，节点采用贪婪算法（局部最优），不能保证全局最优，可以随机抽取样本，训练多个树</li>
<li>过于复杂的概念，无法表达</li>
</ul>

<h2 id="sklearn-example"><a class="headerlink" href="#sklearn-example" title="sklearn example"></a>sklearn example</h2><pre><code>import numpy as np
import matplotlib.pyplot as plt

<p>from sklearn.datasets import load_iris<br/>from sklearn.tree import DecisionTreeClassifier</p>
<h1 id="Parameters"><a class="headerlink" href="#Parameters" title="Parameters"></a>Parameters</h1><p>n_classes = 3<br/>plot_colors = “ryb”<br/>plot_step = 0.02</p>
<h1 id="Load-data"><a class="headerlink" href="#Load-data" title="Load data"></a>Load data</h1><p>iris = load_iris()</p>
<p>for pairidx, pair in enumerate([[0, 1], [0, 2], [0, 3],<br/>                                [1, 2], [1, 3], [2, 3]]):<br/>    # We only take the two corresponding features<br/>    X = iris.data[:, pair]<br/>    y = iris.target</p>
<pre><code># Train
clf = DecisionTreeClassifier().fit(X, y)

# Plot the decision boundary
plt.subplot(2, 3, pairidx + 1)

x_min, x_max = X[:, 0].min() - 1, X[:, 0].max() + 1
y_min, y_max = X[:, 1].min() - 1, X[:, 1].max() + 1
xx, yy = np.meshgrid(np.arange(x_min, x_max, plot_step),
                     np.arange(y_min, y_max, plot_step))
plt.tight_layout(h_pad=0.5, w_pad=0.5, pad=2.5)

Z = clf.predict(np.c_[xx.ravel(), yy.ravel()])
Z = Z.reshape(xx.shape)
cs = plt.contourf(xx, yy, Z, cmap=plt.cm.RdYlBu)

plt.xlabel(iris.feature_names[pair[0]])
plt.ylabel(iris.feature_names[pair[1]])

# Plot the training points
for i, color in zip(range(n_classes), plot_colors):
    idx = np.where(y == i)
    plt.scatter(X[idx, 0], X[idx, 1], c=color, label=iris.target_names[i],
                cmap=plt.cm.RdYlBu, edgecolor='black', s=15)
</code></pre>
<p>plt.suptitle(“Decision surface of a decision tree using paired features”)<br/>plt.legend(loc=’lower right’, borderpad=0, handletextpad=0)<br/>plt.axis(“tight”)<br/>plt.show()<br/></p></code></pre>

import numpy as np

<h2 id="多输出问题"><a class="headerlink" href="#多输出问题" title="多输出问题"></a>多输出问题</h2><pre><code>import numpy as np
import matplotlib.pyplot as plt
from sklearn.tree import DecisionTreeRegressor

<h1 id="Create-a-random-dataset-1"><a class="headerlink" href="#Create-a-random-dataset-1" title="Create a random dataset"></a>Create a random dataset</h1><p>rng = np.random.RandomState(1)<br/>X = np.sort(200 * rng.rand(100, 1) - 100, axis=0)<br/>y = np.array([np.pi * np.sin(X).ravel(), np.pi * np.cos(X).ravel()]).T #输出X正弦 余弦<br/>y[::5, :] += (0.5 - rng.rand(20, 2)) #干扰</p>
<h1 id="Fit-regression-model-1"><a class="headerlink" href="#Fit-regression-model-1" title="Fit regression model"></a>Fit regression model</h1><p>regr_1 = DecisionTreeRegressor(max_depth=2)<br/>regr_2 = DecisionTreeRegressor(max_depth=5)<br/>regr_3 = DecisionTreeRegressor(max_depth=8)<br/>regr_1.fit(X, y)<br/>regr_2.fit(X, y)<br/>regr_3.fit(X, y)</p>
<h1 id="Predict-1"><a class="headerlink" href="#Predict-1" title="Predict"></a>Predict</h1><p>X_test = np.arange(-100.0, 100.0, 0.01)[:, np.newaxis]<br/>y_1 = regr_1.predict(X_test)<br/>y_2 = regr_2.predict(X_test)<br/>y_3 = regr_3.predict(X_test)</p>
<h1 id="Plot-the-results-1"><a class="headerlink" href="#Plot-the-results-1" title="Plot the results"></a>Plot the results</h1><p>plt.figure()<br/>s = 25<br/>plt.scatter(y[:, 0], y[:, 1], c=”navy”, s=s,<br/>            edgecolor=”black”, label=”data”)<br/>plt.scatter(y_1[:, 0], y_1[:, 1], c=”cornflowerblue”, s=s,<br/>            edgecolor=”black”, label=”max_depth=2”)<br/>plt.scatter(y_2[:, 0], y_2[:, 1], c=”red”, s=s,<br/>            edgecolor=”black”, label=”max_depth=5”)<br/>plt.scatter(y_3[:, 0], y_3[:, 1], c=”orange”, s=s,<br/>            edgecolor=”black”, label=”max_depth=8”)<br/>plt.xlim([-6, 6])<br/>plt.ylim([-6, 6])<br/>plt.xlabel(“target 1”)<br/>plt.ylabel(“target 2”)<br/>plt.title(“Multi-output Decision Tree Regression”)<br/>plt.legend(loc=”best”)<br/>plt.show()<br/></p></code></pre>
