<p>使用原型对象的方法创建对象的实列，创建的实例equals原型</p>
<p>final 类型修饰的成员变量不能进行深度拷贝</p>
<h2 id="场景"><a class="headerlink" href="#场景" title="场景"></a>场景</h2><ul>
<li>类初始化需要消化非常多的资源，这个资源包括数据、硬件资源等</li>
<li>构造对象需要非常繁琐的数据准备或访问权限，则可以使用原型模式</li>
<li>工厂模式中使用</li>
<li>共有信息很多</li>
</ul>
<h2 id="浅拷贝"><a class="headerlink" href="#浅拷贝" title="浅拷贝"></a>浅拷贝</h2><p>对象内引用原先原型的对象</p>
<h2 id="深拷贝"><a class="headerlink" href="#深拷贝" title="深拷贝"></a>深拷贝</h2><p>对象内引用也拷贝一份</p>
<h2 id="代码实现"><a class="headerlink" href="#代码实现" title="代码实现"></a>代码实现</h2><pre><code>package prototype;

<p>//Cloneable 标记对象可拷贝<br/>public class PersonClone implements Cloneable {</p>
<pre><code>@Override //Override Object方法
public PersonClone clone(){
    try {
        //clone 不会调用构造方法
        return (PersonClone)super.clone();
    } catch (CloneNotSupportedException e) {
        e.printStackTrace();
    }
    return null;
}
</code></pre>
<p>}</p>
<p>package prototype;</p>
<p>public class MainClass {<br/>    public static void main(String[] args) {<br/>        PersonClone personClone = new PersonClone();<br/>        PersonClone clone = personClone.clone();<br/>        System.out.println(personClone.hashCode());<br/>        System.out.println(clone.hashCode());<br/>    }<br/>}<br/></p></code></pre>
