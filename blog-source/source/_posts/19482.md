<h2 id="线程安全问题"><a class="headerlink" href="#线程安全问题" title="线程安全问题"></a>线程安全问题</h2><p>volatile：保证多线程下的可见性</p>
<blockquote>
<p>读volatile：每当子线程读取volatile变量时，都会从主线程重新拷贝一份<br/>写volatile: 每当子线程修改volatile变量时，都会在修改后同步到主线程去</p>
</blockquote>
<p>synchronized：对象锁、类锁、方法锁（其它篇有介绍）</p>
<pre><code>public class Singleton {

<pre><code>private static volatile Singleton instance;

private Singleton(){
}

public static Singleton getInstance(){
    if(instance == null){
        synchronized(Singleton.class){
            if(instance == null){
                instance = new Singleton();
            }
        }
    }
    return instance;
}
</code></pre>
