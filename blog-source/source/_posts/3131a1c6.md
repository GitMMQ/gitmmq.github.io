<h2>三、Hermes Agent 架构设计 | Hermes Agent Architecture</h2>
<p><strong>中文</strong></p>
<p>Hermes 的架构重心是 <strong>AIAgent 同步编排引擎</strong>（<code>run_agent.py</code>），而非微服务。CLI、Gateway、ACP（IDE 集成）、Cron、Batch Runner 共用同一 Agent 核心。</p>
<div class="note"><p><strong>架构图（Mermaid 源码）</strong> / <em>Architecture diagram (Mermaid source)</em></p><pre><code>flowchart TB
    subgraph Entry["入口层"]
        CLI[CLI / TUI]
        GW[Gateway 20+ 平台]
        ACP[ACP - VS Code/Zed]
        CRON[Cron 调度器]
    end

    subgraph Core["AIAgent 核心引擎"]
        PB[Prompt Builder]
        PR[Provider 解析 18+ 模型]
        TD[Tool Dispatch 70+ 工具]
        CC[上下文压缩]
    end

    subgraph Memory["记忆与学习"]
        WM[工作记忆]
        SM[会话记忆 SQLite+FTS5]
        PM[持久记忆 MEMORY.md/USER.md]
        SKM[技能记忆 Skills]
        HON[Honcho 用户建模]
    end

    subgraph Exec["执行环境"]
        T1[Local]
        T2[Docker]
        T3[SSH]
        T4[Daytona/Modal Serverless]
    end

    Entry --&gt; Core
    Core --&gt; Memory
    Core --&gt; Exec
    Memory --&gt;|闭环学习| SKM</code></pre></div>
<h3>3.1 Agent 循环（Agent Loop）</h3>
<p>标准流程：</p>
<pre><code>用户消息 → 构建 Prompt（系统提示 + 记忆 + 上下文）
         → 调用 LLM（支持 chat_completions / codex_responses / anthropic_messages 三种 API 模式）
         → 解析工具调用 → 执行工具 → 结果回注上下文
         → 循环直至 LLM 不再请求工具 → 返回最终响应 → 持久化会话
</code></pre>
<p>设计原则包括：<strong>提示词稳定性</strong>（会话中不突变，保护前缀缓存）、<strong>可观测执行</strong>（每次工具调用对用户可见）、<strong>可中断</strong>（用户可随时取消）。</p>
<h3>3.2 四层记忆体系</h3>

<p>此外支持 8 种外部记忆 Provider（Honcho、Mem0、Hindsight 等），用于知识图谱、语义检索、跨会话用户建模。</p>
<h3>3.3 闭环学习（Learning Loop）</h3>
<p>Hermes 最核心的差异化能力：</p>
<ol>
<li><strong>策划记忆</strong> — 任务完成后，Agent 自主判断什么值得记住</li>
<li><strong>创建 Skill</strong> — 复杂任务（通常 5+ 次工具调用）成功后，自动生成 Markdown 格式 Skill</li>
<li><strong>Skill 自改进</strong> — 执行失败或发现更优路径时，通过 <code>skill_manage</code> 工具 patch 更新</li>
<li><strong>周期性微调（Periodic Nudge）</strong> — 会话间隙触发自我反思与优化</li>
<li><strong>FTS5 召回</strong> — 按需检索历史，经 LLM 摘要后注入相关片段</li>
</ol>
<p>技能库可从几十个增长到上百个，而上下文 Token 成本几乎不变（仅加载索引 + 按需全文）。</p>
<h3>3.4 工具与执行环境</h3>
<ul>
<li><strong>70+ 工具</strong>，28 个 toolsets，模块级自注册（<code>registry.register()</code>）</li>
<li><strong>6 种终端后端</strong>：Local、Docker、SSH、Daytona、Modal、Singularity</li>
<li><strong>5 种浏览器后端</strong> + MCP 双向支持（既可作 MCP 客户端，也可被 Cursor/VS Code 接入）</li>
<li><strong>子 Agent 委派</strong>：<code>delegate_tool</code> 生成隔离子代理并行处理</li>
</ul>
<h3>3.5 Gateway 与多渠道</h3>
<p>单一 Gateway 进程支持 20 个平台适配器：Telegram、Discord、Slack、WhatsApp、Signal、Matrix、钉钉、飞书、企业微信、QQ 等。与 CLI 共享斜杠命令（<code>/model</code>、<code>/skills</code>、<code>/compress</code> 等）。</p>
<p><strong>English</strong></p>
<p>Hermes centers on the <strong>AIAgent synchronous orchestration engine</strong> (<code>run_agent.py</code>) — not microservices. CLI, Gateway, ACP (IDE), Cron, and Batch Runner share one agent core.</p>
<h3>3.1 Agent Loop</h3>
<pre><code>User message → Build prompt (system + memory + context)
            → Call LLM (3 API modes: chat_completions / codex_responses / anthropic_messages)
            → Parse tool calls → Execute → Inject results
            → Loop until no more tool calls → Final response → Persist session
</code></pre>
<p>Design principles: <strong>prompt stability</strong> (no mid-session mutations, preserves prefix cache), <strong>observable execution</strong>, <strong>interruptibility</strong>.</p>

<h3>3.3 Closed Learning Loop</h3>
<p>Hermes's key differentiator:</p>
<ol>
<li><strong>Curate memory</strong> — after tasks, decide what's worth remembering</li>
<li><strong>Create skills</strong> — auto-generate Markdown skills after complex tasks (typically 5+ tool calls)</li>
<li><strong>Self-improve skills</strong> — patch via <code>skill_manage</code> on failure or better paths</li>
<li><strong>Periodic Nudge</strong> — self-reflection between sessions</li>
<li><strong>FTS5 recall</strong> — search history, LLM-summarize, inject relevant snippets</li>
</ol>
<p>Skill libraries can grow from dozens to hundreds with near-flat context token cost.</p>
<h3>3.4 Tools &amp; Execution Environments</h3>
<ul>
<li><strong>70+ tools</strong>, 28 toolsets, self-registering at import time</li>
<li><strong>6 terminal backends</strong>: Local, Docker, SSH, Daytona, Modal, Singularity</li>
<li><strong>5 browser backends</strong> + bidirectional MCP (client and server for Cursor/VS Code)</li>
<li><strong>Sub-agent delegation</strong> via <code>delegate_tool</code></li>
</ul>
<h3>3.5 Gateway &amp; Multi-Channel</h3>
<p>One Gateway process, 20 platform adapters: Telegram, Discord, Slack, WhatsApp, Signal, Matrix, DingTalk, Feishu, WeCom, QQ, etc. Shares slash commands with CLI (<code>/model</code>, <code>/skills</code>, <code>/compress</code>).</p>

<p><strong>优点</strong><br/>
- 社区体量极大，文档、教程、第三方 Skills 丰富<br/>
- Gateway 架构简洁直观，「一个进程、一个端口」易于理解<br/>
- 渠道覆盖广（50+），含 iOS/Android Nodes、Web Control UI<br/>
- 工作区文件（SOUL.md 等）人类可读、可 Git 版本管理<br/>
- 本地优先，数据主权在用户手中<br/>
- 上手快：<code>openclaw onboard</code> 引导式安装</p>
<p><strong>缺点</strong><br/>
- 记忆与技能主要靠人工维护，缺少内置自学习闭环<br/>
- 技能不会随使用自动优化，重复任务仍需重新推理<br/>
- 广泛文件/系统访问带来安全风险，需仔细配置 allowlist<br/>
- 云模型 API 费用可能较高（$10–150+/月，视用量而定）<br/>
- 静态配置为主，「越用越懂你」需额外 Skills 或手动维护 MEMORY.md</p>
<h3>Hermes Agent</h3>
<p><strong>优点</strong><br/>
- 唯一内置完整闭环学习的 Agent 框架<br/>
- 技能自动生成与自我迭代，重复任务效率显著提升<br/>
- 四层记忆 + FTS5 按需检索，Token 成本可控<br/>
- 模型无关，支持 18+ Provider（OpenRouter、NIM、Kimi、GLM 等）<br/>
- 6 种执行后端 + Serverless，$5 VPS 到 GPU 集群均可<br/>
- 官方提供 OpenClaw 迁移工具，降低切换成本<br/>
- 研究友好：轨迹导出、批量 Runner、RL 环境支持</p>
<p><strong>缺点</strong><br/>
- 生态较新，社区规模小于 OpenClaw<br/>
- 学习闭环增加系统复杂度，调试需理解记忆/技能机制<br/>
- 持久记忆有字符上限（MEMORY.md ~2200 字符），需主动整合<br/>
- 企业集成与大型社区插件市场仍在建设中<br/>
- Windows 需 WSL2，不支持原生 Windows</p>
<p><strong>English</strong></p>
<h3>OpenClaw (Lobster)</h3>
<p><strong>Pros</strong><br/>
- Massive community, docs, tutorials, third-party skills<br/>
- Simple Gateway: one process, one port<br/>
- Broad channel coverage (50+), iOS/Android nodes, Web Control UI<br/>
- Human-readable workspace files, Git-versionable<br/>
- Local-first, user data sovereignty<br/>
- Fast onboarding via <code>openclaw onboard</code></p>
<p><strong>Cons</strong><br/>
- Memory and skills mostly manual; no built-in self-learning loop<br/>
- Skills don't auto-improve; repeated tasks re-reason each time<br/>
- Broad file/system access raises security risk; careful allowlist config needed<br/>
- Cloud model API costs can be high ($10–150+/month depending on usage)<br/>
- Static config; "knows you better over time" needs extra skills or manual MEMORY.md</p>
<h3>Hermes Agent</h3>
<p><strong>Pros</strong><br/>
- Only major framework with a built-in closed learning loop<br/>
- Auto-generated, self-improving skills; big gains on repeated tasks<br/>
- Four-layer memory + FTS5 on-demand recall; controlled token cost<br/>
- Model-agnostic, 18+ providers (OpenRouter, NIM, Kimi, GLM, etc.)<br/>
- 6 execution backends + serverless; $5 VPS to GPU cluster<br/>
- Official OpenClaw migration tool<br/>
- Research-ready: trajectory export, batch runner, RL environments</p>
<p><strong>Cons</strong><br/>
- Newer ecosystem, smaller community than OpenClaw<br/>
- Learning loop adds complexity; debugging requires understanding memory/skills<br/>
- Persistent memory has char limits (~2200 for MEMORY.md); active consolidation needed<br/>
- Enterprise integrations and large plugin marketplace still maturing<br/>
- Windows requires WSL2; no native Windows</p>

<h2>九、结语 | Conclusion</h2>
<p><strong>中文</strong></p>
<p>Agent Hermes 与 OpenClaw（龙虾）代表了个人 AI Agent 的两条演进路线：<strong>连接广度</strong> 与 <strong>学习深度</strong>。龙虾用 Gateway 把 AI 带进你的消息应用和工作区；Hermes 用闭环学习让 AI 从每一次任务中沉淀经验。在实际部署中，二者可以共存、迁移、甚至互补——关键取决于你是更需要「随时随地的多渠道助理」，还是「越用越懂你的自进化伙伴」。</p>
<p><strong>English</strong></p>
<p>Agent Hermes and OpenClaw (Lobster) represent two evolution paths for personal AI agents: <strong>connectivity breadth</strong> vs. <strong>learning depth</strong>. OpenClaw's Gateway brings AI into your messaging apps and workspace; Hermes's closed loop turns every task into lasting experience. In practice they can coexist, migrate, and complement each other — the choice depends on whether you need an always-available multi-channel assistant or a self-evolving partner that knows you better over time.</p>
