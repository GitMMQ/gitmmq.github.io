<ol>
<li>初始状态：一对刚出生的兔子</li>
<li>下一步：生长</li>
<li><code>繁殖得到 一对刚出生的兔子-&gt; 第1步</code></li>
</ol>
<p>总结： 当月的兔子数=上月兔子数+当月新生兔子  数列的当前列=前两列之和</p>

<h2 id="数组记录先两项值"><a class="headerlink" href="#数组记录先两项值" title="数组记录先两项值"></a>数组记录先两项值</h2><p>时间复杂度从指数阶降到了多项式阶O(n),空间复杂度O(n)</p>
<pre><code>Fib2(intn)
{
    if(n&lt;1)
        return-1;
    int[] a=new int[n];
    a[1]=1;
    a[2]=1;
    for(int i=3;i&lt;=n;i++)
        a[i]=a[i-1]+a[i-2];
        return a[n];
     }
}

<pre><code>Fib3(intn)
{
    inti,s1,s2;

 }

       public static int[][] muliMatrix(int[][] m1,int[][] m2){
           int [][] res=new int[m1.length][m2[0].length];
           for(int i=0;i&lt;m1.length;i++){
               for(int j=0;j&lt;m2[0].length;j++){
                   for(int k=0;k&lt;m2.length;k++){
                       res[i][j]+=m1[i][k]*m2[k][j];
                   }
               }
           }
           return res;
       }
