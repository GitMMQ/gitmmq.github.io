<p>开发过程中，需要根据不同场景选择不同算法和策略。</p>
<p>将需要经常改变的部分抽象提取为接口，通过引用该接口，就可以调用该接口实现类的行为，即具体策略。实现了策略具体实现和调用者的隔离。</p>
<h3 id="优点"><a class="headerlink" href="#优点" title="优点"></a>优点</h3><ol>
<li>可以动态改变对象行为</li>
</ol>
<h3 id="缺点"><a class="headerlink" href="#缺点" title="缺点"></a>缺点</h3><ol>
<li>使用哪种策略需要调用者自己决定</li>
<li>产生很多策略类</li>
</ol>
<h2 id="示例"><a class="headerlink" href="#示例" title="示例"></a>示例</h2><pre><code>public interface IStrategy {
    public void doSomething();
}

public class Strategy1 implements IStrategy {
    @Override
    public void doSomething() {

    }
}

public class Strategy2 implements IStrategy {
    @Override
    public void doSomething() {

    }
}

public class Context implements IStrategy {

    private IStrategy strategy;

    public Context(IStrategy strategy){
        this.strategy = strategy;
    }

    @Override
    public void doSomething() {
        strategy.doSomething();
    }
}

public static void main(String[] args) {
    IStrategy strategy = new Strategy1();
    Context context = new Context(strategy);
    context.doSomething();
}
</code></pre>
