<p>List&lt;String&gt; list2 = list1.stream().filter(s -&gt; !s.equals(“1”)).collect(Collectors.toList());<br/>System.out.println(list2.toString());<br/></p></code></pre>
<h3 id="函数接口"><a class="headerlink" href="#函数接口" title="函数接口"></a>函数接口</h3><p>一个只包含一个方法的接口,可以使用Lambda表达式作为参数</p>
<pre><code>new Thread(() -&gt; System.out.println("Hello World!"));

<p>public interface Interface1 {<br/>     void test();<br/>}</p>
<p>private void func(Interface1 interface1) {<br/>    interface1.test();<br/>}</p>
<p>func(() -&gt; System.out.println(“Hello World”));</p>
<p>//有参数，参数知名类型更规范<br/>func((Integer x) -&gt; System.out.println(“Hello World” + x));</p>
<p>//有参数，有返回值<br/>func((Integer x) -&gt; {<br/>    System.out.println(“Hello World” + x);<br/>    return true;<br/>});<br/></p></code></pre>
