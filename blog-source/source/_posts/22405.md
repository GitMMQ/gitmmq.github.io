<h3 id="函数接口"><a class="headerlink" href="#函数接口" title="函数接口"></a>函数接口</h3><p>一个只包含一个方法的接口,可以使用Lambda表达式作为参数</p>
<pre><code>new Thread(() -&gt; System.out.println("Hello World!"));

public interface Interface1 {
     void test();
}

private void func(Interface1 interface1) {
    interface1.test();
}

func(() -&gt; System.out.println("Hello World"));

//有参数，参数知名类型更规范
func((Integer x) -&gt; System.out.println("Hello World" + x));

//有参数，有返回值
func((Integer x) -&gt; {
    System.out.println("Hello World" + x);
    return true;
});
</code></pre>
