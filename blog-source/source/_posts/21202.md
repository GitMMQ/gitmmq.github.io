<p>EL-Spring 表达式语言，支持xml和注解中使用表达式，类似JSP 的EL 表达式，可以实现普通文件、网址、配置文件、系统环境变量的注入</p>
<h2 id="示例"><a class="headerlink" href="#示例" title="示例"></a>示例</h2><pre><code>@PropertySource("classpath:application.properties")

<p>@Value(“This is common string”) // 注入普通字符串<br/>private String normal;</p>
<p>@Value(“#{systemProperties[‘os.name’]}”) // 注入操作系统属性<br/>private String osName;</p>
<p>@Value(“#{T(java.lang.Math).random()*100.0}”) // 注入表达式结果<br/>private double randomNumber;</p>
<p>@Value(“#{anotherService.property}”) // 注入其他Bean属性<br/>private String propfromAnother;</p>
<p>@Value(“#{T(com.demo.el.spring_el_demo.DemoService).getCalc()*100}”) // 注入类static方法结果,支持运算处理<br/>private double result;</p>
<p>@Value(“classpath:test.txt”) // 注入文件资源<br/>private Resource testFile;</p>
<p>@Value(“<a href="http://www.baidu.com/" rel="noopener" target="_blank">http://www.baidu.com</a>“) // 注入网址资源<br/>private Resource testUrl;</p>
<p>@Value(“${book.name}”) // 注入配置文件<br/>private String bookName;</p>
<p>@Autowired<br/>private Environment environment;<br/></p></code></pre>
